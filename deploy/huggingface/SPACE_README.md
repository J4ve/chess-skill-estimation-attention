# RatingNet Prototype

Web prototype for the thesis "Real-Time Chess Skill Estimation and Anomaly Detection Using an Attention-Augmented CNN-BiLSTM": per-move rating estimates, a suspicion score for human fair-play review, critical moves, sample games, and live Lichess games.

Suspicion scores are a review aid, not proof of engine use.

Source: https://github.com/J4ve/chess-skill-estimation-attention
